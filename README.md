# 🤖 AI Resume Analyzer & Job Match Scorer

An intelligent tool combining **ML scoring** and **LLM feedback** to help you optimize your resume.

## 🚀 Features
- PDF resume parsing
- TF-IDF + Cosine Similarity match score
- Claude AI feedback: strengths, gaps, resume bullet suggestions
- Clean Streamlit web interface

## 🛠️ Tech Stack
- Python, Streamlit, Scikit-learn, Anthropic Claude API, PyPDF2

## ⚙️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
